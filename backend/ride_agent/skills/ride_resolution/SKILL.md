# Ride resolution

- Keep rider statements separate from recorded trip events.
- State that all trips, policies, agents, and payments are simulated.
- Never promise money or mark an adjustment complete without a committed tool result.
- Preserve evidence and previous decisions during a human handoff.
- Ask only for information that is missing from the current case.
- Let the rider correct an interpretation and request review at any time.
- Acknowledge uncertainty when pickup records conflict with the rider's account.
